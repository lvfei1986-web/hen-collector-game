## Context

这是一个从零开始的浏览器端小游戏项目。项目目录当前为空仓库（仅含 openspec 配置），无历史代码需要兼容或迁移。所有功能须在单页面内完成，不依赖后端。

## Goals / Non-Goals

**Goals:**
- 使用 HTML5 Canvas 实现 60fps 的流畅游戏循环
- 使用 TypeScript + Vite 构建，代码组织清晰（实体、系统、AI 分层）
- 实现完整的游戏流程：主菜单 → 游戏中 → 结束画面 → 榜单
- 所有状态数据存储在客户端（localStorage）
- 提供基础视觉美术（Canvas 矢量绘制或简单贴图）

**Non-Goals:**
- 不实现多人在线或实时联网对战
- 不实现移动端触屏控制（仅 PC 键盘）
- 不实现音效/BGM（视觉反馈足够）
- 不做复杂的物理引擎集成（AABB 碰撞够用）
- 不做关卡编辑或自定义地图

## Decisions

### D1: 技术栈 — HTML5 Canvas + TypeScript + Vite
- **选择**: 使用原生 Canvas 2D API 而非 Phaser/Pixi.js 等游戏引擎
- **理由**: 游戏规模小（单屏、少量实体），原生 Canvas 足够且无额外学习负担，打包体积最小
- **备选方案**: Phaser.js — 功能强大但学习成本高，引入约 200KB 运行时，对本项目而言过重

### D2: 架构 — 实体-系统模式（Entity-System Pattern）
- **选择**: 将游戏拆分为 Entity 基类 + 各子系统（MovementSystem、CollisionSystem、AISystem、SkillSystem、ItemSystem），统一由 GameLoop 驱动
- **理由**: 实体行为解耦，添加新实体或新系统不影响现有代码。Eagle 和 Hen 共享部分移动逻辑，可通过继承 Entity 复用
- **备选方案**: 面向对象的巨类（Game 类包含所有逻辑）— 初期看似简单，但后期难以维护

### D3: 地图与坐标 — 固定画布尺寸 + 世界像素坐标
- **选择**: 画布固定 800x600 像素，所有实体以 {x, y} 像素坐标定位。不做相机/滚动，所有内容可见
- **理由**: 单屏游戏不需要滚动，降低复杂度
- **备选方案**: 网格系统（类似贪吃蛇）— 不符合需求的自由移动体验

### D4: 碰撞检测 — AABB 矩形重叠
- **选择**: 每个实体维护一个 bounding box，使用轴对齐包围盒做相交检测
- **理由**: 简单且对该游戏足够，避免圆形碰撞的额外开销
- **备选方案**: 圆形碰撞 — 实体是方块/圆时效果更好，但 AABB 实现更直接

### D5: 老鹰 AI — 简单贪心追击 + 障碍物绕行
- **选择**: 每帧计算老鹰到队尾小鸡的方向向量，朝该方向移动；碰到障碍物时尝试左右偏移 30° 方向
- **理由**: 比 A* 寻路简单得多，游戏地图不大、障碍物不多，贪心 + 绕行足够产生可信追击行为
- **备选方案**: A* 网格寻路 — 实现复杂，维护成本高，收益微小

### D6: 蛇形跟随 — 记录路径点
- **选择**: 母鸡维护一个 path 数组，记录最近 N 个坐标点（N = 队伍最大长度）。每只小鸡跟随它前方的实体的 path[distance 索引] 位置
- **理由**: 经典贪吃蛇实现方式，小鸡间距固定，转弯自然
- **备选方案**: 每只小鸡独立朝前方小鸡移动 — 会导致队伍松散，间距不稳定

### D7: 数据存储 — localStorage 键 `hen-game-leaderboard`
- **选择**: JSON 数组存储，每条记录 `{name: string, time: number, won: boolean, timestamp: number}`
- **理由**: 浏览器端唯一可靠持久化方式，简单直观
- **备选方案**: IndexedDB — 对小型数据过重

## Risks / Trade-offs

- **[老鹰 AI 绕障不够聪明]** → 先实现简单绕行，若测试中出现卡住问题再加方向回溯机制
- **[Canvas 渲染性能]** → 实体数量少（母鸡 + ≤10 小鸡 + 1 老鹰 + ≤3 道具 + ≤10 障碍），60fps 无压力。若出现问题可对障碍物做脏矩形裁剪
- **[WASD 在浏览器中被页面滚动干扰]** → 游戏中用 `preventDefault` 拦截键盘事件，锁定游戏区域焦点
- **[localStorage 存储上限]** → 榜单 20 条记录远低于 5MB 限制，不会触发
