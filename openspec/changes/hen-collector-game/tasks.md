- [x] 3.1 实现 MapGenerator：随机生成矩形障碍物，不重叠，不超过地图面积 30%，母鸡起始位置在中央且远离障碍

- [x] 3.4 实现队伍管理：母鸡吸收自由小鸡时追加到队伍末尾，path 数组扩容

- [x] 3.7 实现胜负判定：老鹰命数归零 → 母鸡胜利；队伍长度为 0（最后小鸡被捉）→ 老鹰胜利
